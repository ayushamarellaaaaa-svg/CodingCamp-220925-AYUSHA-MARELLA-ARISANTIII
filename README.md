## Deskripsi Proyek
Website ini adalah portofolio interaktif RevoU yang menampilkan profil perusahaan, showcase portfolio, dan halaman untuk mengirim pesan.  

Website terdiri dari 4 halaman utama:

1. *home.html* – Halaman utama dengan hero section dan informasi ringkas.  
2. *profil.html* – Profil perusahaan RevoU, lokasi kantor, dan informasi headquarter.  
3. *portfolio.html* – Showcase proyek dan portfolio RevoU.  
4. *message-us.html* – Formulir untuk mengirim pesan ke perusahaan.  

Website menggunakan:

- HTML, CSS, dan JavaScript  
- Particles.js – animasi background partikel  
- Typed.js – animasi teks typing  
- AOS – animasi saat scroll  
- Desain responsive untuk mobile dan desktop  

---

## Fitur Utama

- Animasi partikel interaktif di background setiap halaman  
- Teks animasi menggunakan Typed.js pada hero section  
- Navbar dinamis dengan efek scroll dan burger menu di mobile  
- Animasi AOS saat scroll untuk semua card dan section  
- Form Message Us dengan validasi sederhana  
- Responsif untuk semua ukuran layar

## Cara Menjalankan

### 1. Menjalankan secara Lokal
1. Pastikan struktur folder tetap sama seperti di atas.  
2. Buka salah satu halaman, misalnya home.html, menggunakan browser modern seperti Chrome, Firefox, atau Edge.  
3. Gunakan navbar untuk navigasi ke halaman lain: Profil, Portfolio, atau Message Us.  
4. Semua animasi (Particles.js, Typed.js, AOS) akan berjalan otomatis.  

### 2. Menjalankan via GitHub Pages
1. Upload seluruh folder proyek ke repository GitHub.  
2. Masuk ke *Settings → Pages* pada repository GitHub.  
3. Pilih branch yang ingin digunakan (misalnya main) dan folder root (/) sebagai source.  
4. Simpan pengaturan, GitHub akan memberi link live website.  
5. Buka link tersebut di browser, dan seluruh halaman serta animasi akan berjalan sama seperti lokal.
